# 📊 每日股票分析系统

## 项目信息

- **课程**: 高级数据结构与算法
- **小组**: 朱浩钧、张世勇、孙烨
- **主题**: 基于 OpenClaw 的多智能体协作系统 - 每日股票分析

## 智能体分工

| 智能体 | 负责人 | 职责 |
|--------|--------|------|
| 大盘分析师 | 朱浩钧 | 分析上证指数、深证成指、创业板指等主要指数 |
| 板块分析师 | 张世勇 | 分析热门行业板块资金流向 |
| 个股分析师 | 孙烨 | 分析指定板块内的重点股票 |
| 报告汇总 | 待开发 | 整合三方报告，生成操作建议 |

## 技术栈

- **数据获取**: akshare（免费财经数据接口）
- **数据分析**: pandas, numpy
- **技术指标**: 自定义实现（MA、MACD、RSI等）
- **可视化**: matplotlib, seaborn
- **定时任务**: GitHub Actions（免费）
- **Web UI**: Gradio（待开发）

## 安装运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行分析

```bash
python main.py
```

### 3. 查看报告

报告生成在 `reports/` 目录下，格式为 `daily_report_YYYYMMDD.txt`

## 数据源

- 上证指数 (sh000001)
- 深证成指 (sz399001)
- 创业板指 (sz399006)
